## 🎯 Tujuan / Latar Belakang Project
Proyek ini dibuat sebagai tugas kelompopk untuk mempraktikkan HTML, CSS, dan JavaScript sederhana sekaligus kerjasama tim menggunakan Github (Branch, Commit, Pull Request, dan Merge). Isinya memperkenalkan komunitas Maxguads, mendokumentasikan prestasi turnamen dan menyediakan jalur kontak bagi pengunjung website.

---

## Fitur / Section
- Home / Hero: perkenalan tim, efek teks mengetik, dan slider foto otomatis
- About: profil singkat komunitas
- Pencapaian Kami: kartu prestasi lengkap dengan foto, kategori, deskripsi, dan tag
- Contact & Footer: form kontak dan tautan media sosial
